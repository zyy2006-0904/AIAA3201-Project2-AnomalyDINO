# Third-Party Components

This project builds on the following open-source resources:

- AnomalyDINO: `https://github.com/dammsi/AnomalyDINO`
- DINOv2: `https://github.com/facebookresearch/dinov2`
- VisA official data preparation:
  `https://github.com/amazon-science/spot-diff`
- CVPR author template: `https://github.com/cvpr-org/author-kit`

The vendored AnomalyDINO source retains its original license. Dataset files
are not redistributed. The course server stores the official VisA archive in a
shared read-only location.
